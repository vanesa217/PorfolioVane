# VT Solutions · Vanesa Carolina Tarelli

> Portafolio profesional de desarrollo frontend moderno, ingeniería de control y automatización industrial.

## 🚀 Tecnologías & Stack
- **Frontend & Web:** HTML5 semántico, CSS3 moderno, JavaScript ES6+, diseño ultra-responsive y arquitectura modular.
- **Automatización & Control:** Lógica Ladder, tableros eléctricos, electroneumática, CADe SIMU y esquemas EPLAN.
- **Herramientas & Productividad con IA:** Google Antigravity, Google Gemini, GitHub Copilot, Claude, ChatGPT, Vite y VS Code.

## 📦 Ejecución Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
